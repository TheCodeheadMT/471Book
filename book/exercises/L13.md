**1. The Bellman Update Calculation** 

An autonomous reconnaissance drone is currently in the state $S_{recon}$. It is running Value Iteration to determine its optimal tactical value, looking ahead to the next time step. It has two possible actions: **Loiter** or **Advance**. 

You are given the following environmental dynamics and current value estimates ($V_k$) for the surrounding states. The discount factor is $\gamma = 0.5$.

*   **Current State Values ($V_k$):**
    *   $V_k(S_{recon}) = 2$
    *   $V_k(S_{target}) = 20$
    *   $V_k(S_{danger}) = -10$

*   **Action 1: Loiter**
    *   100% probability ($T=1.0$) of remaining in $S_{recon}$.
    *   Immediate reward: $+1$.

*   **Action 2: Advance**
    *   80% probability ($T=0.8$) of reaching $S_{target}$ with an immediate reward of $+10$.
    *   20% probability ($T=0.2$) of drifting into $S_{danger}$ with an immediate reward of $-5$.

Calculate the specific action-values (Q-values) for both actions, and determine the updated state value $V_{k+1}(S_{recon})$.

<details>
  <summary>Show solution</summary>

  **Step 1:** Calculate the expected value of the **Loiter** action using the Bellman summation: $\sum T [R + \gamma V_k]$.

  * $Q(\text{Loiter}) = 1.0 \times [1 + 0.5(2)]$
  * $Q(\text{Loiter}) = 1.0 \times [1 + 1] = 2$

  **Step 2:** Calculate the expected value of the **Advance** action, accounting for both stochastic outcomes.

  * Target Outcome: $0.8 \times [10 + 0.5(20)] = 0.8 \times [20] = 16$
  * Danger Outcome: $0.2 \times [-5 + 0.5(-10)] = 0.2 \times [-10] = -2$
  * $Q(\text{Advance}) = 16 + (-2) = 14$

  **Step 3:** Apply the $\max$ operator to find the updated state value.

  * $V_{k+1} = \max(Q(\text{Loiter}), Q(\text{Advance}))$
  * $V_{k+1} = \max(2, 14)$

  **Answer:**

  The updated state value $V_{k+1}(S_{recon})$ is **14**. The agent achieves this by taking the **Advance** action.

</details>

**2. The Uniqueness of Value Iteration**

A junior AI engineer is reviewing the deployment code for a new combat agent. They notice that the Value Iteration algorithm never actually stores or evaluates a specific "playbook" (a policy, $\pi$) while it is running its loops. It only extracts the policy at the very end. 

Explain what makes Value Iteration unique in this regard. How does it guarantee finding the optimal policy without tracking one, and what specific pieces of environmental data are absolutely mandatory for this algorithm to work?

<details>
  <summary>Show solution</summary>

  **Step** 1: Identify the core mechanic of the Value Iteration update equation.<br>
  **Step 2:** Identify the dependencies (the variables) required to execute the math.<br>
  
  **Answer:**

  Value Iteration is unique because it implicitly builds the optimal policy by aggressively applying the **$\max_a$ operator** at every single step of the calculation. Instead of locking into a specific policy and evaluating how good it is (which is what *Policy Iteration* does), Value Iteration constantly assumes the agent will make the absolute perfect choice moving forward, focusing strictly on calculating the raw numerical utility of the states.

  Furthermore, Value Iteration is a **model-based** algorithm. To perform these expected value calculations, it strictly requires a perfect map of the environment's dynamics: it must know the exact Transition Probabilities ($T$) and the exact Reward Functions ($R$). In future lessons, we will explore model-free algorithms (like *Q-Learning*) that must learn these values through physical trial and error because they do not have access to $T$ and $R$.

**3. Interpreting Convergence**

An automated theater-defense system is running Value Iteration on a massive grid of states. 
* At Iteration 50, the policy extracted from the values dictates that the optimal move in Sector 4 is to deploy interceptors. 
* At Iteration 500, the policy extracted *still* dictates deploying interceptors in Sector 4, and the tactical playbook has not changed for any other sector. 
* However, the mathematical state values ($V$) are still increasing by $0.0001$ with every iteration.

Has the system converged optimally, and should the commander halt the algorithm to save compute cycles? Explain the difference between value convergence and policy convergence.

<details>
  <summary>Show solution</summary>
  
  **Step 1:** Define the difference between policy convergence and value convergence.
  
  **Step 2:** Apply this dynamic programming principle to the commander's decision.

  **Answer:**

  Yes, the system has practically converged, and the commander should halt the algorithm and extract the policy.
  
  **Policy convergence** occurs when the optimal actions stop changing. **Value convergence** occurs when the exact mathematical numbers of the state values stop changing. Because of the discount factor ($\gamma$) and the asymptotic nature of the Bellman update, the raw numerical values ($V$) will often continue to creep upward by microscopic fractions for hundreds of iterations. However, the optimal policy (the actual tactical decisions) typically crystallizes long before the math settles. Since the playbook is no longer changing, computing further iterations is a waste of resources. 
</details>
